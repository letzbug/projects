Eclipse Broadcast Control

Remote broadcast control system for a live solar eclipse event.

THE BUILD

Overview

Eclipse Broadcast Control is a browser-based remote control system created for a live solar eclipse event in Ettelbruck. The system allows a moderator using an iPad to control, in real time, what is shown on a separate computer connected to the event projector.

The complete workflow runs through standard web technologies using GitHub Pages and Supabase. No dedicated local application or server software has to be installed on the moderator device or presentation computer.

How it works

The moderator interface provides direct access to several live eclipse sources and local backup material. Selecting a source instantly sends the requested state to the presentation screen, where the corresponding broadcast or event content is displayed.

The system was designed around the requirements of a live event: simple operation, very fast switching and clear visual feedback about the source currently on screen.

Live sources &amp; fallback

Multiple broadcast sources can be prepared in advance, including official live productions, telescope feeds and web-based emergency backups. A local eclipse simulation can also be kept available as an independent fallback if external streams become unavailable.

Quick actions

Dedicated controls give the moderator immediate access to essential event functions such as a black screen, the event slide, screen reload and standby mode. These actions avoid navigating through menus when something has to change immediately during the live presentation.

Technical approach

The project combines a responsive iPad control interface, a dedicated projector display page, GitHub Pages for static hosting and Supabase for synchronising the current presentation state between both devices. This makes the solution lightweight, portable and usable from any modern browser.

Purpose

The goal was to turn a conventional projector setup into a remotely operated event broadcast system without adding specialised broadcast hardware or locally installed control software. The moderator can remain on stage with the audience while the presentation computer stays connected to the projector in the background.
